# OCR and Handwriting Guide

Turn paper, receipts, and handwritten notes into clean, searchable text —
using free OCR tools and free AI, explained like a friend would explain it.

This is a beginner manual for the full pipeline: shooting phone photos that
OCR reads correctly the first time, picking the right free tool for the job,
cleaning up garbled output with AI prompts you can copy-paste, and filing
everything so future-you can find it with one search.

**Part of a series by [Asdale Dynamics, LLC](https://dylanasdale.github.io) —
plain-English AI education, step by step, never condescending.**
Companion guides: the *PDF Everyday Handbook* (working with PDFs), the
*Photo Digitizing Guide* (archival photos), and the *Paperwork Organizer*
(life-admin filing).

## Read the polished version

A static HTML edition lives in [`site/`](site/) — same manual, styled for
reading, no build step and no server needed. Open `site/index.html`
straight from the file manager (double-click) and it just works.

## Quick start (60 seconds)

```bash
# Read the manual from your terminal, or open the HTML site:
xdg-open site/index.html      # Linux
open site/index.html          # macOS
start site/index.html         # Windows
```

Everything runs on free tools (phone built-ins, Google Lens/Drive, free AI
chat tiers, Tesseract). No accounts beyond a free one, no subscriptions, no
API keys — and none of the files here contain or require any secrets.
